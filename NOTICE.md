# Configuration provenance

The public profile is a cleaned snapshot of Roobahist's personal configuration,
used with the owner's authorization. It carries no private Git history.

The Alacritty palette is the GitHub Dark palette; attribution to
https://github.com/alacritty/alacritty-theme is retained in the theme file.
Application names, glyphs and font references belong to their respective owners.
Fonts and third-party apps are installed separately, not redistributed here.

Vorssaint's public source was consulted to identify preference storage and native
export behavior. No Vorssaint implementation source is bundled in this project.
The profile contains the owner's portable preference values, not private content.

Unused SketchyBar example plugins are excluded from the public profile.
